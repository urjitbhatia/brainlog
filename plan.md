│ Context                                                                                                                                                                                                                                                  │
│                                                                                                                                                                                                                                                          │
│ Brainlog is a Rust CLI tool that transparently wraps executables (like time) to capture their stdout, stderr, and stdin streams. It stores logs in a framed binary format and service metadata in SQLite. An MCP server exposes tools for LLM agents to  │
│ discover services and query logs. Optional LLM integration provides auto-enrichment of service metadata and semantic search.                                                                                                                             │
│                                                                                                                                                                                                                                                          │
│ ---                                                                                                                                                                                                                                                      │
│ Architecture Overview                                                                                                                                                                                                                                    │
│                                                                                                                                                                                                                                                          │
│ brainlog run --name web --tag project:pimlico -- npm start                                                                                                                                                                                               │
│   |                                                                                                                                                                                                                                                      │
│   +-> SQLite: create service + run rows                                                                                                                                                                                                                  │
│   +-> Log files: ~/.brainlog/logs/<run-id>/{stdout,stderr,stdin,combined}.log                                                                                                                                                                            │
│   +-> Background: LLM enrichment (name/description generation)                                                                                                                                                                                           │
│   +-> Background: port detection polling (lsof)                                                                                                                                                                                                          │
│   +-> Child process: PTY (if terminal) or pipe spawning                                                                                                                                                                                                  │
│   +-> Signal forwarding: SIGINT, SIGTERM, SIGQUIT, etc.                                                                                                                                                                                                  │
│   +-> I/O tee: passthrough to terminal + write framed log files                                                                                                                                                                                          │
│   +-> On exit: update run status, flush logs, exit with child's code                                                                                                                                                                                     │
│                                                                                                                                                                                                                                                          │
│ brainlog mcp (separate process, stdio transport)                                                                                                                                                                                                         │
│   |                                                                                                                                                                                                                                                      │
│   +-> Read-only SQLite connection (WAL mode)                                                                                                                                                                                                             │
│   +-> Tools: discover_services, get_logs, search_logs                                                                                                                                                                                                    │
│   +-> Optional LLM client for semantic service matching                                                                                                                                                                                                  │
│                                                                                                                                                                                                                                                          │
│ ---                                                                                                                                                                                                                                                      │
│ CLI Interface                                                                                                                                                                                                                                            │
│                                                                                                                                                                                                                                                          │
│ Two invocation styles, both equivalent:                                                                                                                                                                                                                  │
│                                                                                                                                                                                                                                                          │
│ # Direct mode (default, like `time`) — anything not a known subcommand is a command to wrap                                                                                                                                                              │
│ brainlog pnpm run dev                                                                                                                                                                                                                                    │
│ brainlog --name web --tag project:pimlico pnpm run dev                                                                                                                                                                                                   │
│                                                                                                                                                                                                                                                          │
│ # Explicit subcommand mode (also supported)                                                                                                                                                                                                              │
│ brainlog run --name web -- pnpm run dev                                                                                                                                                                                                                  │
│                                                                                                                                                                                                                                                          │
│ # Management subcommands (reserved names)                                                                                                                                                                                                                │
│ brainlog list                                                                                                                                                                                                                                            │
│ brainlog logs <id> --tail 50                                                                                                                                                                                                                             │
│ brainlog search "error"                                                                                                                                                                                                                                  │
│ brainlog mcp                                                                                                                                                                                                                                             │
│                                                                                                                                                                                                                                                          │
│ Parsing strategy: Use clap with external_subcommand or custom pre-parsing. Known subcommands are run, list, logs, search, mcp. If argv[1] is NOT a known subcommand, treat the entire tail as a command to wrap (direct mode). Brainlog's own flags      │
│ (--name, --tag, --desc) are parsed greedily before the first unrecognized positional arg, which starts the target command.                                                                                                                               │
│                                                                                                                                                                                                                                                          │
│ Implementation: In main.rs, before clap dispatch, peek at argv. If argv[1] matches a known subcommand, delegate to clap normally. Otherwise, manually split argv into brainlog flags + target command, then call the run handler directly.               │

│ ---                                                                                                                                                                                                                                                      │
│ Log Frame Format                                                                                                                                                                                                                                         │
│                                                                                                                                                                                                                                                          │
│ Binary format for all log files (stdout.log, stderr.log, stdin.log, combined.log):                                                                                                                                                                       │
│                                                                                                                                                                                                                                                          │
│ [timestamp_ns: u64 LE][stream_type: u8][length: u32 LE][payload: [u8; length]]                                                                                                                                                                           │
│                                                                                                                                                                                                                                                          │
│ - Header: 13 bytes per frame                                                                                                                                                                                                                             │
│ - stream_type: 0x01=stdout, 0x02=stderr, 0x03=stdin                                                                                                                                                                                                      │
│ - Payload: raw bytes preserved exactly (ANSI, binary, UTF-8)                                                                                                                                                                                             │
│                                                                                                                                                                                                                                                          │
│ LogWriter: tokio task receiving Frame via mpsc channel, buffered flush every 100ms or 64KB. Writes to per-stream file AND combined file.                                                                                                                 │
│                                                                                                                                                                                                                                                          │
│ LogReader: forward scan (head), backward scan (tail), time-range filter, follow mode (poll file size).                                                                                                                                                   │
│                                                                                                                                                                                                                                                          │
│ ---                                                                                                                                                                                                                                                      │
│ Process Wrapper                                                                                                                                                                                                                                          │
│                                                                                                                                                                                                                                                          │
│ PTY vs Pipe decision (process/mod.rs): stdin.is_terminal() -> PTY, else pipes.                                                                                                                                                                           │
│                                                                                                                                                                                                                                                          │
│ PTY mode (process/pty.rs):                                                                                                                                                                                                                               │
│ 1. nix::pty::forkpty() for PTY pair                                                                                                                                                                                                                      │
│ 2. Child: exec target on PTY slave                                                                                                                                                                                                                       │
│ 3. Parent: save terminal attrs, set raw mode, handle SIGWINCH                                                                                                                                                                                            │
│ 4. I/O pump: stdin -> PTY master (+ tee), PTY master -> stdout (+ tee)                                                                                                                                                                                   │
│ 5. Note: PTY merges stdout/stderr; stderr.log empty in PTY mode                                                                                                                                                                                          │
│ 6. On exit: restore terminal, exit with child's code                                                                                                                                                                                                     │
│                                                                                                                                                                                                                                                          │
│ Pipe mode (process/pipe.rs):                                                                                                                                                                                                                             │
│ 1. tokio::process::Command with piped stdin/stdout/stderr                                                                                                                                                                                                │
│ 2. Three concurrent tee tasks                                                                                                                                                                                                                            │
│ 3. Separate stdout/stderr capture                                                                                                                                                                                                                        │
│                                                                                                                                                                                                                                                          │
│ Signals (process/signals.rs):                                                                                                                                                                                                                            │
│ - signal-hook-tokio for async signal streams                                                                                                                                                                                                             │
│ - Forward: SIGINT, SIGTERM, SIGQUIT, SIGHUP, SIGUSR1, SIGUSR2, SIGCONT                                                                                                                                                                                   │
│ - SIGWINCH -> PTY resize (PTY mode only)                                                                                                                                                                                                                 │
│ - brainlog catches SIGINT itself; only exits when child exits                                                                                                                                                                                            │
│                                                                                                                                                                                                                                                          │
